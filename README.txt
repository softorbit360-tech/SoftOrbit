# SoftOrbit v3

## Folder structure
SoftOrbit v3/
├── index.html
├── css/style.css
├── js/app.js
├── js/data.js
└── assets/images/

## Run
1. Open the folder in VS Code.
2. Open index.html with Live Server (recommended), or open index.html directly in a browser.
3. The site works as a static frontend. Feedback/comments use localStorage.
4. Selecting a non-English language dynamically loads Google Translate; Internet access is required for that translation.

## Important
- Replace LINK3_GATEWAY, AGNI_PRIMARY_GATEWAY, AGNI_SECONDARY_GATEWAY and LINK4_GATEWAY with the real values before using MikroTik commands.
- The MikroTik examples are learning/reference material, not a production-ready configuration for an unknown RouterOS environment.
- Code blocks are marked notranslate so translation does not rewrite commands.
