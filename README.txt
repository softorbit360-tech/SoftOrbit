SoftOrbit v3 — Integrated IT Knowledge Hub

This build treats CrowdStrike as ONE module/category inside the same SoftOrbit knowledge database alongside Active Directory, MikroTik, Networking, Windows and CCTV.

Run:
1. Extract the ZIP.
2. Keep the folder structure unchanged.
3. Open index.html in Edge/Chrome.

Search and category filters work locally. Topic cards open a common SoftOrbit troubleshooting playbook. Feedback/comments use browser localStorage.

CrowdStrike content is based on public CrowdStrike documentation and is intentionally written as a knowledge/reference module, not as a live tenant controller. Verify exact Falcon licensing, OS support, console UI and API scopes before production changes.
